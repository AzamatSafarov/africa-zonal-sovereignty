# Zonal Sovereignty Atlas — Africa crypto regimes, 2013–2026

Интерактивный атлас: как крипто-хабы и особые экономические режимы перестраивают Африку, и как это меняет представление о суверенитете.

**Live:** https://africa-zonal-sovereignty.vercel.app

> **Демонстрационный корпус.** Данные собраны из открытых источников и **не верифицированы построчно** по первоисточникам. Не использовать в публикации без проверки. Каждая запись помечена уровнем достоверности: `sourced` (есть конкретный источник) или `reported` (обзорная, не сверена).

## Головоломка

Нигерия запретила криптовалюту банковским циркуляром в феврале 2021 — и занимает **второе место в мире** по бытовому использованию крипты. Египет криминализовал любые операции (ст. 206 Закона о ЦБ № 194/2020) — и входит в топ-30 по adoption.

Мозамбик и Замбия ничего не запрещали — и не имеют ни рынка, ни хабов.

**Формальное регулирование не определяет, где развивается хаб.**

## Рамка

**Graduated sovereignty** (Aihwa Ong, 1999/2006). Государство не теряет суверенитет, а перераспределяет его применение: на ограниченной территории действует иной правовой режим, чтобы встроиться в глобальные потоки. Зона — инструмент конвертации суверенитета в доступ к сети.

**Развилка, которую нужно проговорить.** Ong описывала сильные государства Юго-Восточной Азии. В африканских кейсах государство часто слабое, и зона может быть симптомом отсутствия стратегии, а не её инструментом. Рабочий вопрос: *крипто-зона — инструмент суверенной стратегии или симптом её отсутствия?*

## Методы (вложенная конструкция)

Внешний круг держит паттерн, внутренние объясняют механизм.

| Уровень | Метод | Вопрос |
|---|---|---|
| Основание | Event analysis (хронология + атрибуция) | что принято, кем, в каком порядке |
| Пространство | Срезы по годам, кластеризация | где и как идёт волна |
| **Ядро** | **Сетевой анализ** | кто с кем связан, роль страны |
| Глубина | Кейсы + ретроспектива | почему именно там |

Прогноз: **не заявляется**. Event analysis используется как хронология с атрибуцией, не как экстраполяция.

## Данные

- 19 стран, 173 записи таймлайна (2013–2026)
- 6 внешних узлов (Дубай, Сингапур, Гонконг, Цюрих, Абу-Даби, БВО)
- 10 рёбер сети
- 64 записи `sourced`, 109 `reported`

Реестр режимов: `prohibitive` / `restrictive` / `drafting` / `sandbox` / `licensing` / `open` — по годам.

## Структура

```
data/atlas-data.json     — реестр (страны, таймлайны, узлы, рёбра)
site/index.html          — атлас (данные встроены, без fetch)
site/countries-110m.json — геометрия (Natural Earth, 110m)
qa_main.py               — проверка интерактивности и рендера
qa_vp.py                 — проверка вьюпортов 1440/390/320
qa_bbox.py               — проверка кадрирования карты
```

## Запуск локально

```bash
cd site
python -m http.server 8931
# → http://127.0.0.1:8931
```

Геометрия стран подгружается отдельным файлом, поэтому нужен HTTP-сервер (не `file://`).

## Проверено

- 19 стран отрисованы, 10 рёбер с путями, 0 JS-ошибок
- Нет горизонтального overflow на 1440 / 390 / 320
- Слайдер перекрашивает карту: 2013 → 3 страны с событиями, 2021 → 15, 2026 → 19
- Живой деплой отвечает 200, карта грузится
- Полный континент в кадре, включая юг Африки и Мадагаскар

## Ограничения

- Годы режимов 2013–2017 кодированы обзорно — требуют сверки
- Реестр рёбер неполон (10 из ~60–100)
